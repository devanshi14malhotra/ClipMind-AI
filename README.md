# ClipMind-AI 🎥🧠

ClipMind-AI is an advanced, AI-powered video intelligence platform. It automatically processes uploaded videos or YouTube links to generate highly accurate transcripts, multi-paragraph summaries, and precise "key moments" (with clickable timestamps) using Whisper and LLaMA models. It also features a robust analytics dashboard to track video insights and trending keywords.

## ✨ Features

- **Local & YouTube Video Upload**: Drag-and-drop local files or simply paste a YouTube URL to ingest videos.
- **AI Transcriptions**: High-accuracy speech-to-text conversion powered by Whisper AI.
- **AI Summarization**: Deep, multi-paragraph semantic summaries generated by LLaMA-3.
- **Key Moments Generation**: AI-identified video highlights with exact, clickable timestamps that automatically seek the video player to the right moment.
- **Analytics Dashboard**: Interactive charts and data visualizations (powered by Recharts) showing total watch time saved, trending keywords, and library statistics.
- **Role-Based Access Control (RBAC)**: Secure user profiles and feature gating based on user roles (Admin, Creator, Learner, etc.).
- **Seamless UI**: A beautiful, glassmorphic, dark-mode Next.js frontend with smooth transitions and real-time updates without page reloading.

## 🛠 Tech Stack

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS, Recharts
- **Backend**: Python, FastAPI, SQLAlchemy, MongoDB (Motor), Groq API (Whisper & LLaMA)
- **Infrastructure**: Docker & Docker Compose (for database services)

## 🚀 Getting Started

Follow these instructions to run the application locally on your machine.

### 1. Start Database Services
Make sure you are in the main project directory and have Docker installed and running.
```bash
docker-compose up -d
```

### 2. Start the Backend
Open a new terminal window, navigate to the `backend` folder, and start the FastAPI server.

```bash
cd backend

# Create a virtual environment (first time only)
# python -m venv venv

# Activate the virtual environment
# On Windows:
.\venv\Scripts\activate
# On Mac/Linux:
# source venv/bin/activate

# Install dependencies (first time only)
# pip install -r requirements.txt

# Start the development server
uvicorn main:app --reload
```
*The backend will be available at `http://localhost:8000`*

### 3. Start the Frontend
Open another terminal window, navigate to the `frontend` folder, and start the Next.js development server.

```bash
cd frontend

# Install dependencies (first time only)
# npm install

# Start the development server
npm run dev
```
*The frontend will be available at `http://localhost:3000` (or `3001` if 3000 is in use).*

## 🔑 Environment Variables
Ensure you have the required `.env` files set up in both the `/backend` and `/frontend` directories with your respective API keys (e.g., Groq API Key) and database connection strings.
